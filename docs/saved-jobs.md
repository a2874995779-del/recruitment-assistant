# 已保存岗位管理

入口为桌面顶部“已保存岗位”。读取本地记录无需 BOSS 登录；“更新选中原帖”和“原站详情”需要可访问的原网页。

## 分类与备注

- 四种分类：待考虑、优先查看、已手动沟通、不合适。沿用原有 `CONSIDERING / INTERESTED / CONTACTED / REJECTED` 值，已有个人标记保持。
- 展开岗位“备注”，输入后点击“保存备注”。最多 2000 字，仅存在本地。备注不自动提交给招聘平台。
- 分类与备注独立于招聘状态。手动标记已沟通不发送消息，也不代表职位仍在招聘。

## 本地筛选与排序

- 关键词搜索岗位、企业与已保存备注，公司和地点也可分别输入。
- 修改条件后点击“应用筛选”；“重置”清空条件。“刷新本地记录”只重新查询数据库。
- 月薪单位为 K/月，日薪单位为元/天，分别比较，不换算周期。金额区间有交集即匹配，如日薪 200–220 与查询 210–215 匹配。
- 薪资为空、字体受限、面议或周期无法确认时，不参与金额筛选或按周期筛选；不限周期与金额时仍显示。
- 按薪资排序需先选择周期，按区间下限、上限排序。按保存时间排序使用首次本地保存时间，后续刷新不改变这个时间。
- 筛选和统计在分页之前完成，每页 50 条；勾选项可用于对比或手动启动原帖更新，切换筛选和分页后清空选择。

## 按需更新原帖

1. 在 BOSS 网页自行登录并打开岗位列表或详情。
2. 返回已保存岗位，勾选要核实的记录，点击“更新选中原帖”。每次最多 20 条、总预算 120 秒、逐条加载最多 12 秒。
3. 软件使用既有会话顺序读取官方岗位详情，不点击沟通或投递，不提交表单，不手动调用私有接口。
4. 只有岗位链接、名称与企业一致，并且本次详情薪资可读、地点明确时，才更新记录。描述、学历与经验读到时同时更新；缺少的非核心字段保留旧值。
5. 同样的薪资也可以成功核实并更新观察时间。显示首次保存、读取、最近成功更新、最近尝试时间；失败或停止的尝试不会覆盖最近成功时间。
6. 登录/安全验证跳转、连续三次失败、停止、原网页导航、超时或关闭窗口都会结束读取。失败保留旧岗位、分类、备注与成功时间，迟到结果不写入。未检查项可再次手动选择更新。

数据时间是软件读取时间，不是发布/更新/关闭时间。详情身份变化或页面兼容失败时保留旧信息并提示手动核对，不能据此将岗位自动标为失效。

更新本地保存记录不修改搜索工作台里的历史观察快照，也不改变默认跳过已保存岗位的规则。恢复历史记录不自动访问原站。

## 岗位对比与变化记录（2026-10-13）

勾选 2–4 个岗位后点击“对比所选”，并排查看薪资、地点、学历、经验、福利标签、地址、描述和本地备注。只比较当前本地观察，不访问原站；不同工资周期不换算。

“更新选中原帖”同时检查字段变化：薪资、地点、学历、经验、标签、职位描述和工作地址。每次成功读取显示“岗位有变化”或“本次未发现变化”，展开“查看变化记录”查看旧值、新值和核实时间。保留最近 20 次有变化的检查，每项长文本展示前 2000 字；没有变化的检查仅更新最近成功检查时间，不重复增加历史。

缺失的非核心字段沿用旧值，不当作删除；原先没有读取到的字段后来补全，也记录为本地字段变化，不代表原站刚修改过。更新失败或停止显示“本次未核实”，保存历史和旧值保持；登录跳转、字段识别失败不能判定岗位下架。本功能手动触发，无后台定时扫描或自动沟通。无需数据库升级，变化记录随本地库持久化。

## 存储与兼容

复用 SQLite 岗位库及 settings 表。分类、备注、尝试记录以岗位 ID 隔离保存，更新复用原岗位 ID 与首次保存时间；无需修改数据库版本或清空已有数据。筛选使用参数化 SQL，文本中的引号、百分号与下划线按普通字符处理。现有 BOSS 沟通和简历发送能力仍关闭。
