# 已保存岗位的招呼语与沟通（代码阶段，未测试）

在“已保存岗位”展开“设置招呼语”，编辑后保存到本机。支持 `{岗位}`、`{公司}` 占位符，替换后的文本最多 500 字。

每条记录新增“一键打招呼”和“打开沟通”。打招呼先核对原站当前会话的岗位链接、岗位名及公司，再生成两分钟内有效的单次预览；用户确认后提交该条文本。打开沟通不提交文本。不附带简历，也没有定时发送或批量发送。

当前实现仅适配已有会话的明确沟通链接，或已经打开且身份可核对的会话。首次建立会话的“立即沟通”可能直接发送 BOSS 默认招呼，所以不自动点击；没有明确入口时停在原帖，由使用者自行操作。原站输入框已有草稿时，不覆盖草稿，不跳转。

发送前持久化 PENDING；只有原站发出消息气泡出现同样文本，才记录 SENT（页面回显，不等同送达）。点击后没有明确回显、页面变化或程序异常记为 UNKNOWN；程序中断留下的 PENDING 也阻止重复发送。只有明确未点击发送的失败可再次尝试；无自动重试。发送文本、时间和状态保存在本机岗位设置中，和“已手动沟通”个人分类分开。
